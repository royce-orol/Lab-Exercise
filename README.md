# Lab Exercises Enhancements

## Overview
This project contains enhanced versions of selected lab exercises to provide future students with a deeper understanding of the materials. The enhancements clarify concepts, explore advanced topics, provide visualizations, apply the materials to real-world datasets, and compare different methods or approaches. Each enhancement is presented in a separate Jupyter Notebook, ensuring compatibility with both Google Colab and Visual Studio Code (with the Jupyter extension).

## Enhanced Lab Exercises
The following lab exercises have been enhanced:

1. **Principal Component Analysis (PCA)**
   - Clarifies the concept of PCA and its mathematical foundation.
   - Provides visualizations to illustrate how PCA reduces dimensionality.
   - Applies PCA to a real-world dataset to demonstrate its use in data preprocessing.
   - Compares PCA with other dimensionality reduction techniques.

2. **Linear Regression**
   - Explores simple and multiple linear regression models.
   - Provides visualizations of regression lines and residuals.
   - Applies linear regression to real-world datasets to demonstrate its effectiveness.
   - Compares different optimization methods for parameter estimation.

3. **Gradient Descent (Part A)**
   - Explains the theory behind gradient descent optimization.
   - Visualizes the gradient descent process and convergence.
   - Applies gradient descent to a real-world regression problem.
   - Compares gradient descent with other optimization algorithms.

4. **PyTorch Fundamentals**
   - Introduces the basics of PyTorch for deep learning.
   - Demonstrates tensor operations and automatic differentiation.
   - Applies PyTorch to a simple neural network implementation.
   - Compares PyTorch with other deep learning frameworks.

## File Structure
Each enhanced lab exercise is provided in a separate Jupyter Notebook:
- `1_LabEnhancements_PCA.ipynb`
- `2_LabEnhancement_LinearRegression.ipynb`
- `3_LabEnhancements_LogisticRegression.ipynb`
- `4_LabEnhancements_PyTorch.ipynb`

## Requirements
To run these notebooks, ensure you have the following installed:
- Python 3.x
- Jupyter Notebook or Jupyter Lab
- Google Colab (if running on the cloud)
- Required Python libraries :
  - NumPy
  - Pandas
  - Matplotlib
  - Scikit-learn
  - PyTorch

## Execution Instructions
- **Google Colab:** Upload the notebooks to Google Drive and open them in Colab.
- **Visual Studio Code:** Open the notebooks in VS Code with the Jupyter extension enabled.
